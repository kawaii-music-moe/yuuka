# Bot 登録名と Discord アカウント名の同期

対象は Bot アカウント名（username）。サーバーのニックネームは対象外。

| 操作 | 同期 OFF | 同期 ON |
| --- | --- | --- |
| 名前を保存 | 登録名だけ更新 | Discord 更新成功後に登録名も更新 |
| ON に切り替え | REST で現在の Discord 名を取得し、登録名を上書き | 現在の Discord 名を再取得 |
| OFF に切り替え | 名前を維持 | 名前を維持して同期だけ解除 |
| Discord 側で名前を変更 | 登録名を維持 | USER_UPDATE と起動時・定期同期で追従 |

- ON にする際の取得失敗では、名前と同期状態を維持する。
- ON 中の保存で Discord が更新を拒否した場合、登録名を維持し、画面の入力を残す。
- 未連携・停止中・無効トークンでは ON にできない。OFF への切り替えは Discord に依存しない。
- 編集中に ON にすると未保存の入力を Discord 名で置き換える。OFF にすると入力を維持する。
- 同期状態は DB に保存し、再読み込み・再起動後も維持する。
- 同じ Discord アカウントを複数の Bot で使う場合、アカウント名変更は全体に影響する。同期 ON の登録名は追従し、OFF の登録名は維持する。
- 登録名の保存と同期切り替えは別操作。空白名・50文字超の登録名は拒否し、Discord 側の追加制約は Discord の更新結果で判定する。
- 変更権限は既存どおり Bot 所有者。別 Bot や共有デフォルトの Discord クライアントにはフォールバックしない。
